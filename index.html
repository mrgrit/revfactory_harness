하네스 엔지니어링 with Claude Code

Claude Code를 "한 번의 대화를 잘 굴리는 도구"가 아니라 작업 환경(=하네스)을 미리 세팅해두는 도구로 다루는 법을 실습 한 개씩 순서대로 익힙니다. 각 실습은 배경 → 하네스 구성 → 실행 → 결과 비교 → 정리 흐름으로 진행됩니다.

📘
교재와 예제 출처
이 강의는 《하네스엔지니어링 with Claude Code》(한빛미디어) 와 저자의 공개 예제 저장소 revfactory/harness-engineering-with-cc (Apache-2.0) 를 바탕으로 합니다. 책 본문의 저작권은 저자와 한빛미디어에 있습니다.

실습 준비물

  • Claude Code 최신 버전 — npm install -g @anthropic-ai/claude-code 후 claude 로 로그인
  • Git 과 터미널 (macOS · Linux · WSL 권장)
  • Node.js 20+, Python 3.10+ — 일부 실습(8장·11장·13장)에서 사용
  • 예제 저장소 클론: git clone https://github.com/revfactory/harness-engineering-with-cc.git

진행 방식

  1. 개념 확인해당 절이 다루는 하네스 개념(에이전트·스킬·경계·안전장치)을 짧게 정리합니다.
  2. 하네스 구성.claude/agents/, .claude/skills/, CLAUDE.md 를 직접 읽고 왜 그렇게 설계됐는지 봅니다.
  3. 실행동일한 프롬프트를 실제로 실행하고 산출물을 확인합니다.
  4. 비교·정리하네스 적용 전/후 또는 변형 간 차이를 표로 비교하고, 내 프로젝트에 적용할 포인트를 정리합니다.

커리큘럼

실습은 순차적으로 공개됩니다. 공개 표시가 있는 항목만 열 수 있습니다.
